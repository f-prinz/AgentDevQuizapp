# Changes

Eingangskorb fuer aufgeschobene Aenderungswuensche. Jeder Eintrag traegt ein Typ-Tag:
`[CHG]` Aenderung an Bestehendem | `[FEAT]` neue Funktionalitaet (User Story) | `[BUG]` Fehler.
Dringendes wird direkt im Gespraech gemeldet und landet nicht hier.
Format-Vorlagen fuer Eintraege: `docs/templates/request-*.md`.
